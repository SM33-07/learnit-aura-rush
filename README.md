## ⚡ MODE 1: TAKE THE LEAD (1–6 Player Multiplayer Arena)

**TAKE THE LEAD** turns any stall display, projector, or laptop into a live spectator arena where 1 to 6 students battle in real time on their smartphones.

### 🕹️ How It Works:
1. **Booth Projector (`/host/[code]`)**:
   - Host clicks **`⚡ CREATE & HOST ARENA MATCH`**.
   - A high-contrast QR code and 6 squad pods appear on screen.
2. **Instant Phone Join (`/play/[code]`)**:
   - Up to 6 students scan the QR code with their phone cameras.
   - Enter a nickname and get assigned a unique avatar in **under 3 seconds**. (7th player is rejected with `ROOM FULL`).
3. **The 6-Round Blitz Match (< 2.5 minutes total)**:
   - **Round 1 (Reflex Strike)**: Speed-tap center flash (Attendance proxy call, hot samosa drop, accidental screenshare panic).
   - **Round 2 (Aura Mathematics)**: Gen-Z slang dilemmas (Waving back at a stranger = -10,000 Aura, Rizzology, Delulu index).
   - **Round 3 (Everyday Pop-Tech)**: 1-in-20 accessible digital lore (What Incognito Mode actually hides, Indian IT restart fix).
   - **Round 4 (Campus Survival)**: Hostel & exam lore (2:30 AM hostel UNO brawl outcome, cutting chai/powerbank/proxy trinity).
   - **Round 5 (Tactical Steal Round)**: **⚡ 400 AURA STEAL!** Winner steals 400 Aura from the #1 leader (GPay bill maintenance excuse, presentation next slide guy).
   - **Round 6 (Grand Finale Surge)**: **👑 2× MULTIPLIER + LEADER STEAL!** (8:44 AM iced coffee attendance flex, 11:58:59 PM file name miracle).

### 🃏 Tactical Power Cards (One-Time Use):
Every player gets 4 tactical power cards docked at the bottom of their mobile screen:
- ⚡ **2× SURGE**: Doubles all points earned in the current round.
- 🛡️ **AURA SHIELD**: Absorbs and blocks incoming Aura steals and leader drains.
- 🧲 **LEADER DRAIN**: Siphons 10% Aura directly from the #1 player.
- 🔮 **50/50 REVEAL**: Strikes out 2 incorrect choices on mobile.

### 👑 Final Podium Ceremony & Membership Drive:
- **Big-Screen Crown**: Projector spotlights the #1 Champion with their avatar and score.
- **Mobile Persona Cards**: Each participant receives their personal tier badge (`👑 TIER 9: CERTIFIED MENACE`).
- **One-Tap Membership**: Direct, high-visibility CTA to [Register for LearnIT Membership](https://docs.google.com/forms/d/e/1FAIpQLScdpwK6YjFtwWux8XXBr7tJRYrIlJSdsTNbfT3mahZShdCxHQ/viewform).
- **Next Squad Reset**: Host clicks **`⚡ PLAY AGAIN / NEXT BATTLE →`** to instantly open a fresh lobby.

## 🔥 MODE 2: PLAY SOLO (25-Round Solo Run)

The original high-intensity single-player calibration run:
1. **The Structure**: 25 unique challenges drawn dynamically from a curated **100+ challenge bank**.
2. **Starting State**: Every player starts with **`500 AURA`**.
3. **Timer & Pacing**: 16-second countdown timers for quick decision-making; timeout incurs a **`-60 AURA`** penalty.
4. **Interactive Mechanics**:
   - 🎯 **Deadline Clutch Needle**: Stop the oscillating needle dead inside the green zone.

## 🛠️ Tech Stack & Architecture

- **Framework**: Next.js 15 (App Router, Server Actions & React Client Hooks)
- **Real-Time Engine**: Server-Sent Events (SSE) with 1-second REST polling fallback
- **State Machine**: Server-authoritative room manager (`lib/room-manager.js`) with zero secret leakage
- **Styling**: Vanilla CSS Design System, Space Grotesk & DM Mono typography, custom CRT scan lines, film grain, and frosted glassmorphism (`.question-glass-card`, `.minimal-glass-btn`)
- **Testing**: End-to-end automated multi-client suite (`tests/aura-rush-multiplayer-e2e.mjs`) & solo regression test (`tests/solo-regression-check.mjs`)
- **Deployment**: Vercel CI/CD

## 💻 Local Development & Testing

```bash
# Clone repository
git clone https://github.com/SM33-07/learnit-aura-rush.git
cd learnit-aura-rush

# Install dependencies
npm install

# Run automated multiplayer E2E test suite
node tests/aura-rush-multiplayer-e2e.mjs

# Run solo challenge pool validation
node tests/solo-regression-check.mjs

# Start local server
npm run dev
# or for production preview:
npm run build && npm run start
```

Open [http://localhost:3000](http://localhost:3000) on your desktop and test on phones over your local network (`http://<your-ip>:3000`).
